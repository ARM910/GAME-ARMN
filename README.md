# GAME A R M N — X-O أونلاين

لعبة X-O بقطع تختفي (كل لاعب 3 قطع، الرابعة تمحو الأقدم). المشروع صار X-O فقط.

## الشاشة الرئيسية
- زر **إنشاء غرفة** وزر **انضمام لغرفة**: يفتحان نافذة (Sheet) مباشرة فوق الشاشة الرئيسية بدون الانتقال لصفحة X-O. تعرض النافذة الخيار المطلوب فقط، وفيها رابط صغير للتبديل بينهما. بعد نجاح الإنشاء/الانضمام ينتقل اللاعب لصفحة الغرفة.
- **التصنيف العالمي** واحد فقط: ترتيب اللاعبين حسب **عدد انتصاراتهم أونلاين** (Firebase: `lb/online_xo`).
- رابط صغير للتدرّب ضد الكمبيوتر، والمتجر/الصورة/الإعدادات في الشريط العلوي.

## هيكلة المشروع
```
index.html              الملف النهائي (ملف واحد جاهز للرفع) — يُبنى من src/
manifest.webmanifest    PWA
service-worker.js       كاش أوفلاين (غيّر رقم CACHE عند كل نشر)
icons/  avatars/        الصور
src/
  index.template.html   هيكل الصفحة (الشاشة الرئيسية + شاشة X-O + حول)
  css/                  التنسيقات — الترتيب بالأرقام = ترتيب الـcascade
  js/                   السكربتات — الترتيب بالأرقام = ترتيب التنفيذ
  build.py              python3 src/build.py  ->  index.html
```
أهم الملفات:
- `js/17-xo-game-and-online.js` لعبة X-O + الغرف الأونلاين (إنشاء/انضمام/جولات)
- `js/21-home-ranking-chat.js` الشاشة الرئيسية + التصنيف + البروفايل + الدردشة
- `js/19-accounts-shop-firebase.js` الحسابات، Firebase، المتجر
- `css/38-home-xo.css` تنسيق الشاشة الرئيسية الجديدة
- `css/39-aurora-theme.css` **ثيم Aurora Nebula**: لوحة الألوان الجديدة، الخلفية الموحدة لكل الصفحات، تثبيت ألوان X-O الأصلية، وتنسيق نافذة الغرفة

## ملاحظة مهمة
عدّل ملفات `src/` ثم شغّل `python3 src/build.py`. لا تعدّل `index.html` مباشرة (يُستبدل عند كل بناء).

## الثيم والخلفية
- الخلفية واحدة لكل الصفحات (الرئيسية وX-O): `body::before` + غيوم `#armnPlasma` في `39-aurora-theme.css`. تم حذف خلفية النجوم (`30-stars.js`).
- ألوان لعبة X-O (اللوح، الخلايا، X/O، شريط الغرفة، الدردشة) بقيت كما هي: المتغيرات القديمة مثبّتة داخل `#xo{...}` في نفس الملف.
- لتغيير ألوان الموقع كلها: عدّل متغيرات `:root` في أعلى `39-aurora-theme.css` (`--aur-a/b/c` و`--acc` و`--bg`...).

## ملاحظات التنظيم
- زر الواتساب (رقم التواصل) في آخر الصفحة الرئيسية: HTML داخل `buildHub()` في `21-home-ranking-chat.js`، وتنسيقه `.xh-wa` في نهاية `38-home-xo.css`. لتغيير الرقم عدّل رابط `wa.me/962780653596` والنص المعروض.
- كلاس `hl` محجوز للوغو فقط. أزرار القائمة المميّزة (بروفايلي / دخول) تستخدم `st hi` — لا تستخدم `hl` لأي شيء آخر وإلا ورث تنسيقات اللوغو وتخربطت الواجهة.
- ترتيب الملفات في `index.template.html` هو ترتيب الـcascade؛ آخر ملفات: `38-home-xo.css` ثم `39-aurora-theme.css` ثم `40-perf-ui.js`.
